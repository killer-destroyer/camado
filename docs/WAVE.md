# «Моя волна» — как подбирается музыка

Два режима. **«Хиты · отрывки»** (по умолчанию, с 1.7.0) — актуальные популярные песни; **«Полные · независимые»**
(1.6.0) — полные песни малоизвестных музыкантов, подобранные по звучанию.

## Хиты (1.7.0)

Полные записи известных исполнителей легально отдают только стриминговые сервисы — их Камадо не обходит. Зато у Deezer
есть открытый API: данные «похожие исполнители» (коллаборативная фильтрация — то, на чём стоит «Моя волна» Яндекса),
«радио исполнителя», популярность каждой песни сейчас, даты релизов и официальные 30-секундные отрывки.

1. **Исполнители плейлиста** с весами (чем больше песен — тем важнее; фиты, «Исполнитель - Название» в названии).
2. **Быстрый старт:** «радио» первых исполнителей — волна играет через 1–4 с. Нейросеть не нужна.
3. **Глубже:** похожие исполнители (кто советуется сразу от нескольких исполнителей плейлиста — ближе), их самые
   слушаемые песни, свежие релизы (до года).
4. **Оценка:** близость исполнителя + популярность (для русских песен — «среди своих»: на Deezer они набирают вдвое
   меньше) + свежесть. **Язык — долями**, как в плейлисте. Один исполнитель — не больше 2 из 12; исполнитель из самого
   плейлиста — не больше 1; песни из своей библиотеки исключаются; «не то» убирает исполнителя.
5. **Настроения** — подборки Deezer (Focus, Classical, Acoustic, Dance…), свой вкус — прибавкой.

## Полные песни независимых музыкантов (1.6.0) — подбор по звуку

Цель — как «Моя волна» в Яндексе: бесконечный поток **похожей** музыки, под стиль выбранного плейлиста (или под
настроение), для любых вкусов, с русскими песнями, если плейлист русский. Без обхода стриминговых сервисов.

## Как работает

1. **«Слух».** Нейросеть CLAP (`Xenova/larger_clap_music_and_speech`, 78 МБ, качается один раз) слушает 10 секунд
   песни и выдаёт «отпечаток» — 512 чисел. Похожие по звучанию песни (жанр, инструменты, вокал, настроение) получают
   близкие отпечатки. Работает на компьютере, в фоне; отпечатки сохраняются (`wave-emb.json`).
2. **Плейлист.** Камадо слушает до 12 песен выбранного плейлиста.
3. **Жанры для поиска.** Отпечатки сравниваются с «центрами» 20 жанров (`desktop/shared/waveGenres.ts`, посчитаны по
   ~25 трекам каждого жанра с Audius) — берутся 3 ближайших.
4. **Кандидаты** — с [Audius](https://audius.co) (открытая платформа, официальный API для сторонних программ):
   популярное в этих жанрах, поиск по исполнителям плейлиста, и русские песни (поиск по частым русским словам), если в
   плейлисте есть русские. Песни из своей библиотеки в волну не попадают.
5. **Отбор по звуку.** Кандидатов тоже слушает нейросеть; место в волне — по похожести на 2 ближайшие песни плейлиста
   (так смешанный плейлист не «усредняется»), плюс язык (доля русских как в плейлисте), плюс подстройка: ♡ — ближе к
   этому звучанию, «не то» и пропуск в начале — дальше. Не больше 2 песен одного исполнителя на 10, не подряд.
6. **Настроения** («Бодро», «Спокойно», «Учёба») — как плейлист из центров подходящих жанров; «Что-то новое» — жанры,
   которых в твоей музыке нет. **Характер**: «Незнакомое» или «Популярное» (чаще слушаемое на Audius).

## Как проверяли (13.11.2026)

Выборка: 717 треков с Audius — 20 жанров по ~25 популярных + 206 русскоязычных. У каждого — 20 секунд из середины.
Жанр трека (его ставит сам музыкант на Audius) — «правильный ответ», нейросеть его не видит.

| Проверка | Случайный подбор | Волна |
|---|---|---|
| Плейлист из 6 песен одного жанра → 10 подобранных того же **семейства** (рок/метал/панк, электроника, хип-хоп…) | 20% | **61–64%** |
| …ровно того же жанра | 4% | **33%** |
| Вся цепочка (угадать жанры → кандидаты этих жанров → отбор по звуку) | 18% | **74%** |
| Смешанный плейлист (3 жанра) → подобранное из этих семейств | 46% | **76%** |
| Русский плейлист → русских среди подобранного (только по звуку) | 28% | **65%** |
| …с учётом языка по названиям | 28% | **~85%** (стиль не страдает: 80%) |
| Нерусский плейлист → нерусских | — | **96%** |

Лучше всего — металл, классика, техно, хаус, панк (85–98% того же семейства), хуже — поп, фолк, акустика, джаз
(размытые жанры и на Audius их подписывают как попало). Модель поменьше (`clap-htsat-unfused`, 34 МБ) хуже:
58% стиль и 42% русских — поэтому взята большая.
