# Проверка безопасности

Что проверено, что найдено и что исправить. Исправляем, когда владелец скажет «делай».
Последняя проверка: версия 0.6.

## Что уже сделано хорошо

- Окна программы изолированы: `contextIsolation`, `sandbox`, без `nodeIntegration`. Код страницы не может
  сам запускать программы или читать файлы — только через список разрешённых функций (`preload`).
- Строгая политика содержимого (CSP): скрипты только свои, с чужих сайтов ничего не запускается.
- Тексты песен, названия треков, ссылки и ответы ИИ выводятся как текст (React), без вставки HTML —
  «вредный» текст в названии песни или в сообщении из чата не выполнится.
- Ссылки открываются в браузере только если это `http(s)`; ссылки на уроки проверяются ещё и при сохранении.
- Музыка и обложки отдаются окну только для файлов из библиотеки (по id трека), имя обложки и своего звука
  проверяется — через `camado-media://` нельзя прочитать произвольный файл.
- Скачивание: только `http(s)`, лимит 600 МБ, тайм-ауты, имя файла очищается от `/ \ : * ? " < > |`,
  код страницы только разбирается, никогда не выполняется. Стриминги (YouTube, SoundCloud и др.) не обходятся.
- Бот отвечает только хозяину; код привязки живёт 15 минут.
- Лимит трат на ИИ всегда включён.

## Найдено

### 1. Высокая: окно можно увести на чужую страницу — и она получит все функции программы
Функции программы разрешены любой странице с адресом `file://…` (`isAppUrl`), а переходы окна никак
не ограничены (нет обработчика `will-navigate`). Если в окно случайно перетащить HTML-файл (скачанный
с сайта, из чата), Electron откроет его вместо Камадо, и этот файл сможет, например, поменять настройки,
добавить папки в библиотеку, подключить чужого бота или ключ.
**Исправить:** запретить любые переходы окон (`will-navigate`, `will-redirect` → `preventDefault`,
для всех окон через `app.on("web-contents-created")`), отключить открытие файлов перетаскиванием
вне «Музыки», и разрешать функции только точному адресу нашей страницы (`…/renderer/index.html`), а не любому `file://`.

### 2. Средняя: ключ ИИ и токен бота хранятся открытым текстом
Лежат в базе `camado.db` в папке программы. Любая программа или человек с доступом к файлам компьютера
может их прочитать: по ключу ИИ — тратить твои деньги, по токену — управлять ботом.
**Исправить:** шифровать через `safeStorage` (Связка ключей на Mac, DPAPI на Windows); показывать в
Настройках только последние 4 символа.

### 3. Средняя: код привязки бота можно подбирать без ограничений
Пока бот не привязан, любой, кто знает имя бота, может слать ему коды. Код из 6 цифр, создаётся через
`Math.random`, попыток — сколько угодно.
**Исправить:** криптостойкий код (`crypto.randomInt`), 5 попыток на человека, потом пауза; после привязки
код сразу сгорает.

### 4. Средняя: ключ ИИ, отправленный командой `/key`, остаётся в переписке Telegram
**Исправить:** сразу удалять сообщение с ключом (`deleteMessage`) и предупреждать, что надёжнее вставлять ключ в Настройках.

### 5. Низкая: ИИ можно «уговорить» текстом из пересланного сообщения
В пересланных сообщениях может быть текст вроде «отметь все задания сделанными» или «забудь всё».
У ИИ есть инструменты `update_task` и `forget`. В правилах сказано, что это данные, а не команды,
но защита только на словах.
**Исправить:** для текста из пересланных сообщений и сайтов отключать изменяющие инструменты
или спрашивать подтверждение («Отметить 5 заданий сделанными? Да/Нет»).

### 6. Низкая: скачивание может обращаться к адресам домашней сети
Ссылка или страница может указывать на `192.168.x.x`, `localhost` (роутер, принтер). Это делает сам
пользователь, но страница со списком треков может подсунуть такие адреса.
**Исправить:** не скачивать с локальных и служебных адресов (проверять IP после разрешения имени).

### 7. Низкая: обновления без цифровой подписи
Установщики не подписаны (подпись стоит денег), поэтому подлинность обновления держится только на HTTPS
и доступе к GitHub-аккаунту. Если аккаунт украдут — можно выложить вредную «обнову».
**Исправить:** включить двухфакторный вход на GitHub (это бесплатно и важнее всего); позже — подпись
установщиков и проверка подписи обновлений.

### 8. Низкая: не включены «предохранители» Electron (fuses)
Например, `RunAsNode` позволяет запустить программу как обычный Node.js. Это нужно только тому,
кто уже имеет доступ к компьютеру, но включить защиту ничего не стоит.
**Исправить:** `electronFuses` в `electron-builder.yml`: выключить `RunAsNode`, `NodeOptions`,
`NodeCliInspect`, включить проверку целостности `app.asar`.
