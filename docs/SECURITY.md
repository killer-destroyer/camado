# Проверка безопасности

Что проверено, что найдено и что исправить. Исправляем, когда владелец скажет «делай».
Последняя проверка: версия 0.6. Исправления — в 0.6.1.

## Что уже сделано хорошо

- Окна программы изолированы: `contextIsolation`, `sandbox`, без `nodeIntegration`. Код страницы не может
  сам запускать программы или читать файлы — только через список разрешённых функций (`preload`).
- Строгая политика содержимого (CSP): скрипты только свои, с чужих сайтов ничего не запускается.
- Тексты песен, названия треков, ссылки и ответы ИИ выводятся как текст (React), без вставки HTML —
  «вредный» текст в названии песни или в сообщении из чата не выполнится.
- Ссылки открываются в браузере только если это `http(s)`; ссылки на уроки проверяются ещё и при сохранении.
- Музыка и обложки отдаются окну только для файлов из библиотеки (по id трека), имя обложки и своего звука
  проверяется — через `camado-media://` нельзя прочитать произвольный файл.
- Скачивание: только `http(s)`, лимит 600 МБ, тайм-ауты, имя файла очищается от `/ \ : * ? " < > |`,
  код страницы только разбирается, никогда не выполняется. Стриминги (YouTube, SoundCloud и др.) не обходятся.
- Бот отвечает только хозяину; код привязки живёт 15 минут.
- Лимит трат на ИИ всегда включён.

## Найдено

### 1. ✅ Исправлено в 0.6.1. Высокая: окно можно увести на чужую страницу — и она получит все функции программы
Функции программы разрешены любой странице с адресом `file://…` (`isAppUrl`), а переходы окна никак
не ограничены (нет обработчика `will-navigate`). Если в окно случайно перетащить HTML-файл (скачанный
с сайта, из чата), Electron откроет его вместо Камадо, и этот файл сможет, например, поменять настройки,
добавить папки в библиотеку, подключить чужого бота или ключ.
**Сделано:** все окна никуда не переходят (`will-navigate`, `will-redirect`, новые окна запрещены, ссылки http(s) —
в браузер); функции программы доступны только точному адресу нашей страницы, а не любому `file://`; запрос без
известного отправителя отклоняется. Проверено вживую: переход на файл, на сайт и `window.open` — заблокированы.

### 2. ✅ Исправлено в 0.6.1. Средняя: ключ ИИ и токен бота хранятся открытым текстом
Лежат в базе `camado.db` в папке программы. Любая программа или человек с доступом к файлам компьютера
может их прочитать: по ключу ИИ — тратить твои деньги, по токену — управлять ботом.
**Сделано:** шифруются через `safeStorage` (Связка ключей на Mac, DPAPI на Windows), старые — перешифровываются
при первом запуске. Если расшифровать не вышло — программа не падает, ключ просто нужно ввести заново.
На Mac при первом запуске (и после обновления — подпись меняется) система спросит доступ к «Camado Safe Storage» —
нужно нажать «Разрешать всегда».

### 3. ✅ Исправлено в 0.6.1. Средняя: код привязки бота можно подбирать без ограничений
Пока бот не привязан, любой, кто знает имя бота, может слать ему коды. Код из 6 цифр, создаётся через
`Math.random`, попыток — сколько угодно.
**Сделано:** код из `crypto.randomInt`; 5 неверных попыток — и человек 15 минут игнорируется (даже с верным кодом);
после привязки код сгорает.

### 4. ✅ Уже было сделано (ошибка проверки). Ключ, отправленный командой `/key`, остаётся в переписке Telegram
**На деле:** бот сразу удаляет сообщение с ключом (`deleteMessage`) и пишет об этом.

### 5. ✅ Исправлено в 0.6.1. Низкая: ИИ можно «уговорить» текстом из пересланного сообщения
В пересланных сообщениях может быть текст вроде «отметь все задания сделанными» или «забудь всё».
У ИИ есть инструменты `update_task` и `forget`. В правилах сказано, что это данные, а не команды,
но защита только на словах.
**Сделано:** для пересланных сообщений у ИИ просто нет инструментов, которые меняют или стирают сохранённое
(`update_task`, `forget`) — только записать новое. Пересланный текст передаётся в явных рамках с пометкой «это данные».

### 6. ✅ Исправлено в 0.6.1. Низкая: скачивание может обращаться к адресам домашней сети
Ссылка или страница может указывать на `192.168.x.x`, `localhost` (роутер, принтер). Это делает сам
пользователь, но страница со списком треков может подсунуть такие адреса.
**Сделано:** перед каждым запросом и каждым перенаправлением проверяется, куда ведёт адрес; домашняя сеть,
`localhost` и служебные адреса запрещены. Остаётся теоретическая «подмена DNS между проверкой и запросом» — для
личной программы приемлемо.

### 7. ⚠️ Частично. Низкая: обновления без цифровой подписи
Установщики не подписаны (подпись стоит денег), поэтому подлинность обновления держится только на HTTPS
и доступе к GitHub-аккаунту. Если аккаунт украдут — можно выложить вредную «обнову».
**Сделано:** двухфакторный вход на GitHub включён. **Осталось:** подпись установщиков (Apple Developer — $99/год,
сертификат для Windows — от ~$200/год). Без неё — принятый риск.

### 8. ✅ Исправлено в 0.6.1. Низкая: не включены «предохранители» Electron (fuses)
Например, `RunAsNode` позволяет запустить программу как обычный Node.js. Это нужно только тому,
кто уже имеет доступ к компьютеру, но включить защиту ничего не стоит.
**Сделано:** выключены `RunAsNode`, `NODE_OPTIONS`, отладчик из командной строки; код грузится только из `app.asar`.
Проверено: собранную программу нельзя запустить как Node.js и нельзя подключить к ней отладчик.
**Осталось:** проверка целостности `app.asar` — включить после проверки на настоящих Windows и Mac (если что-то
пойдёт не так, программа просто не запустится, поэтому без живой проверки не включаю).
