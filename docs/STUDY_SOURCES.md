# Источники для подготовки — ПМИ ИТМО

Подборка для функции «Подготовка по программе ИТМО» (см. ROADMAP). Всё бесплатно и законно:
книги ИТМО лежат в открытом доступе на books.ifmo.ru (PDF скачивается без входа, проверено 07.11.2026).
Ссылка на книгу: `https://books.ifmo.ru/book/<номер>/x.htm`.

## Главный источник по темам — Викиконспекты ИТМО

<https://neerc.ifmo.ru/wiki> — конспекты студентов и преподавателей КТ/ПМИ ИТМО, разбиты по темам и семестрам:
матанализ, дискретная математика, алгоритмы и структуры данных, теория вероятностей, линал и др.
Подходит лучше всего: одна тема = одна страница, Камадо может брать её как «прочитай перед занятием».

## Что не подошло
- openbooks.itmo.ru — старый архив (2001–2016), по математике 14 методичек; всё нужное оттуда есть и на books.ifmo.ru.
- is.ifmo.ru/books — страница одной кафедры, в основном «автоматное программирование»; взята только книга Харрисов.

## Как Камадо этим пользуется (план)
Программа дисциплины от владельца (PDF/текст) → темы по занятиям → к каждой теме Камадо подбирает:
страницу Викиконспектов + главу книги из списка выше + 3–5 задач (из типовых расчётов / сборников задач,
по программированию — свои задачи с проверкой ИИ). Без программы — идёт по порядку тем из Викиконспектов.
