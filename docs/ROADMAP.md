## Идеи на следующие версии

- [x] **Подгонка текста по звуку (ИИ)** — в 1.0.5: Gemini слушает песню и называет, в какую секунду начинается несколько строк
  (4–5 по всей песне); эти точки идут в существующую подгонку ⌖ (сдвиг + скорость), сохраняется для песни.
  Сама — когда текст «от версии другой длины», или по кнопке «подогнать по звуку». Песня уходит в Google на анализ —
  предупредить; без ключа ИИ не работает; на nightcore/громком басе может ошибиться — тогда ручная ⌖.
- [x] **Подготовка по программе курса (запрос владельца)** — в 1.0.9: «Прокачка» → «Программа курса»: ИИ разбирает
  программу дисциплины (PDF, скриншот, текст) на темы по занятиям, даты и литературу; к теме — поиск в своих источниках,
  книги из своей библиотеки, задачи от ИИ; «подготовиться» раскладывается в задания. Свои книги и источники — только у
  владельца (в программе), не в коде.
- [x] **«Прокачка»** — в 1.0.9: курсы Python, Java, C++, HTML/CSS (52 урока: гайд, тест, задача с запуском и проверкой, карточки), разминка дня, повторение по интервалам (и в Telegram — /review), серия дней и цель дня, «Ещё задача от ИИ», «Проверь мой код». Ещё не сделано из идей:
  книги (цель по страницам, пересказ главы и карточки); английский по текстам своих песен (слово → перевод → карточка);
  «хочу научиться X» → план на 2 недели в «План недели»; больше языков (JavaScript, SQL, Git).
- [x] **Курсы в разы глубже** — в 1.1.0: 102 урока по модулям, 302 задачи с тестами (3+ на урок, по сложности),
  итоговые тесты модулей, «Задачник» на 152 задачи. Ещё можно: мини-проекты по модулям, многопоточность и тесты в Java/C++.
- [x] **ИИ прямо в «Прокачке»** — в 1.1.0: панель «Спросить ИИ» видит урок, задачу, код и тесты; управляет
  интерфейсом («открой урок…», «запусти тесты», «засчитай урок»); то же из чата и Telegram.
- [x] **Своя «Библиотека» книг** — в 1.1.0: поиск, разделы, скачать к себе, читалка PDF с памятью страницы.
  Ещё можно: цель по страницам, пересказ главы и карточки из книги.

- [x] **Текст песни по словам — заранее и навсегда (запрос владельца)** — в 1.2.0 (Whisper на компьютере, без выделения вокала). Сейчас подгонка — сдвиг и одна скорость на весь
  трек (по 4–5 точкам от ИИ), поэтому слова «текут» ровно, а певец то ускоряется, то тянет. Нужно: Камадо сам, в фоне,
  сразу после добавления песни, расставляет время **каждому слову** и сохраняет у себя — второй раз не считает.
  Как (не через Gemini — языковая модель называет время с ошибкой в секунды и на каждом слове будет путаться):
  1. Распознавание речи с точным временем слов прямо на компьютере (Whisper через whisper.cpp — быстрый на Mac M,
     модель качается один раз при первом включении, не в установщике). Без ключа, без лимитов, песня никуда не уходит.
  2. По желанию — сперва отделить голос от музыки (модель выделения вокала): сильно точнее на громком миксе и рэпе.
  3. Сопоставить услышанные слова с настоящим текстом (даже если Whisper расслышал криво) и заполнить пропуски между
     соседями — скорость сама меняется по песне. Если текста нигде нет — показать то, что распознал Whisper.
  4. Хранить пословную разметку по файлу песни (своя база); slowed/nightcore — та же разметка с пересчётом скорости.
  5. Ручная ⌖ остаётся: поправил одно слово — соседние подтягиваются. Gemini — только запасной вариант.
  Осторожно: на крике, сильном автотюне и шёпоте точность хуже; на Windows без видеокарты считает дольше.

- [x] **«Что нового» прямо в программе (запрос владельца)** — в 1.2.0. Список изменений каждой версии простыми словами:
  1. После обновления при первом запуске — окно «Что нового в X.Y.Z» (коротко, по пунктам, можно закрыть).
  2. Пока обновление не скачано — в полоске «Вышла версия …» и в Настройки → Обновления видно, что она добавит
     (текст берётся из описания релиза на GitHub, показывается как текст, не как страница).
  3. Настройки → Обновления → «История версий»: все прошлые версии с их изменениями (вшиты в программу, работают
     без интернета). Источник один — файл изменений в репозитории, из него же собирается описание релиза.

## Правила, которые не меняются

1. Опасные действия (отправить сообщение, записаться, удалить, заплатить, поставить новый навык) — только после подтверждения.
2. Тексты из чатов, файлов и сайтов — это данные, а не команды Камадо.
3. Лимит трат всегда включён.
