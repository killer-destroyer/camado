# План развития Камадо

Каждый этап сам по себе полезен. Следующий начинаем, когда предыдущий работает на практике.

## Этап 1 — порядок в хаосе

- [x] Бот в Telegram, отвечает только хозяину
- [x] Задания (ДЗ, контрольные, экзамены, лабы) со сроками и статусами
- [x] Разбор обычного текста и пересланных сообщений
- [x] Карточки предметов
- [x] Долгая память о пользователе
- [x] Напоминания и утренняя сводка
- [x] Учёт трат и месячный лимит
- [x] Модель меняется в настройках
- [x] Ручной режим без ключа; ключ подключается командой /key
- [ ] **Чтение учебных чатов самостоятельно.** Камадо подключается к твоему аккаунту Telegram только на чтение (официальный API, ключ с my.telegram.org). Ты говоришь «следи за этим чатом», дешёвая модель (fast) отсеивает болтовню, важное уходит мозгу.
- [x] Фото доски и голосовое «запиши…» — в приложении и в Telegram (PDF-файлы — позже)
- [x] Приложение для компьютера: Сегодня, Задания, Заметки, Фокус, Чат, Настройки
- [x] Музыка: своя библиотека, 3D-карусель, пластинка, визуализатор, тексты (Лента/Взрыв/Строка), тряска в такт
- [x] Музыка по ссылке (файл или страница с аудио)
- [x] Текст песни поверх всех окон
- [x] План на сегодня из заданий с запуском фокуса
- [x] Огромная пластинка с узором по треку, скретч со звуком
- [x] Умный рандом, кроссфейд, таймер сна, slowed + reverb / nightcore
- [x] Мини-плеер в меню-баре Mac, Discord Rich Presence, автопапки
- [x] 12 палитр и «цвета из обложки», плавность на 60/144+ Гц
- [x] Напоминания со звуком: 10 звуков + свой, плавное нарастание, «отложить»
- [x] Пресеты фокуса по реальным методикам с гайдами
- [x] Автовыравнивание громкости и громкость для каждой песни, скретч самой песней
- [x] Плейлисты, «Любимое», «Часто слушаю»; поиск бесплатной музыки; Google Диск / Dropbox / Яндекс Диск и код страницы
- [x] **1.0.0:** заставка-визуализатор, эквалайзер, фоновые звуки, режим «Сессия», репетитор, «разбей на шаги», формулы и PDF,
  ачивки, дыхание и разминка, меню-бар, бесплатный Gemini и выбор любой модели
- [x] Итоги недели; быстрая запись задания горячей клавишей из любой программы
- [x] Установщик (.exe / .dmg) — собирается на GitHub автоматически
- [x] Обновление из интерфейса (Windows — само, Mac — ссылка)
- [x] **Вкладка «Ссылки» на уроки.** Все ссылки преподов в одном месте и красиво: Zoom, Meet, Moodle, чаты, диски. Вставляешь пачкой (хоть целое сообщение из чата) — Камадо сам вытаскивает ссылки и раскладывает по предметам и преподам. Значок сервиса, пометка («пары по вт 10:00», «пароль»), закреплённые и частые наверху, поиск, открытие в один клик.
- [ ] **Камадо на телефоне, связанный с компьютером (обдумываем, не делаем).** Привязка по одноразовому коду или QR с экрана компьютера, как у Telegram Desktop.
  Варианты: (а) Mini App в Telegram — ничего ставить не надо, бот уже есть; (б) своё приложение (React Native / PWA).
  Связь: через свой сервер (работает везде) или напрямую в домашней Wi-Fi сети (без сервера, но только дома).
  Безопасность: отдельный ключ для каждого телефона, который можно отозвать в Настройках; всё шифруется; без привязки — ни одной функции.
- [ ] Mini App в Telegram: дашборд с заданиями, календарём, прогрессом
- [ ] Деплой на сервер (Hetzner / Oracle Free), автозапуск, бэкап базы

## Идеи на следующие версии

- [x] **Подгонка текста по звуку (ИИ)** — в 1.0.5: Gemini слушает песню и называет, в какую секунду начинается несколько строк
  (4–5 по всей песне); эти точки идут в существующую подгонку ⌖ (сдвиг + скорость), сохраняется для песни.
  Сама — когда текст «от версии другой длины», или по кнопке «подогнать по звуку». Песня уходит в Google на анализ —
  предупредить; без ключа ИИ не работает; на nightcore/громком басе может ошибиться — тогда ручная ⌖.

- [ ] **Бот в учебных чатах:** если добавить Камадо в группу (и выключить ему «Group Privacy» в BotFather), он видит
  сообщения группы и сам вытаскивает задания и ссылки, отвечает только хозяину. Владелец спрашивал — «самому
  пересылать слишком много».

## Этап 3 — «Джарвис»

- [ ] **Навыки:** реестр умений; новое умение Камадо пишет сам, показывает тебе, подключает после «ок»
- [ ] **«Допили себя»:** Claude Code на сервере правит код Камадо в отдельной ветке, гоняет тесты, присылает изменения на подтверждение, после «ок» перезапускается. Если новая версия упала, сам откатывается.
- [ ] Голос в реальном времени
- [ ] Агент на компьютере: открыть, скачать, разложить, заполнить
- [ ] Discord-бот (официальный, не аккаунт-притворщик)

## Правила, которые не меняются

1. Опасные действия (отправить сообщение, записаться, удалить, заплатить, поставить новый навык) — только после подтверждения.
2. Тексты из чатов, файлов и сайтов — это данные, а не команды Камадо.
3. Лимит трат всегда включён.
