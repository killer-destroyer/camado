## py-01 | Первая программа: print и переменные
Программа на Python — это команды сверху вниз. `print` выводит на экран:

```python
print("Привет, Камадо!")
print(2 + 3)        # 5
print("a", "b", 1)  # a b 1 — через пробел
```

**Переменная** — имя для значения. Знак `=` значит «положи справа в коробку слева», а не «равно»:

```python
name = "Арсен"
age = 18
age = age + 1      # теперь 19
print(name, age)
```

Основные типы:
- `int` — целые: `7`, `-3`
- `float` — дробные: `3.14` (точка, не запятая)
- `str` — строки в кавычках: `"текст"` или `'текст'`
- `bool` — `True` / `False`

Арифметика: `+ - * /`, целочисленное деление `//`, остаток `%`, степень `**`. `7 / 2` = `3.5`, `7 // 2` = `3`, `7 % 2` = `1`, `2 ** 10` = `1024`.

f-строки вставляют значения в текст: `print(f"Мне {age} лет")`.

= Всё в кавычках — строка, даже если там цифры.

## py-02 | Ввод: input и преобразование типов
`input()` читает строку, которую ввёл пользователь. Важно: **всегда строку**, даже если ввели число.

```python
a = input()        # ввели 5 → a = "5" (строка!)
b = int(input())   # int(...) превращает в число
print(b * 2)
```

Преобразования: `int("12")` → 12, `float("2.5")` → 2.5, `str(10)` → "10".

Несколько чисел в одной строке через пробел:

```python
a, b = map(int, input().split())
print(a + b)
```

`split()` режет строку по пробелам в список: `"3 4".split()` → `["3", "4"]`, а `map(int, ...)` превращает каждый кусок в число.

Частая ошибка: `input() + input()` склеит строки: "2" + "3" = "23".

?? Пользователь ввёл 2 и 3 (каждое в своей строке). Что выведет код?

```python
print(a + b)
```
- 5
+ 23
- 2 3
- ошибка
= input() даёт строки, а + у строк склеивает.

?? Что делает `"10 20 30".split()`?
- возвращает 60
+ возвращает список ["10", "20", "30"]
- возвращает список [10, 20, 30]
- ошибка
= split режет по пробелам, но куски остаются строками.

## py-03 | Условия: if, elif, else
Условие выполняет код, только если выражение истинно. Отступ (4 пробела) показывает, что внутри:

```python
t = int(input())
if t > 25:
    print("жарко")
elif t > 10:
    print("нормально")
else:
    print("холодно")
```

Сравнения: `==` (равно — два знака!), `!=`, `<`, `>`, `<=`, `>=`.
Логика: `and` (и), `or` (или), `not` (не).

```python
if age >= 18 and has_ticket:
    print("проходи")
```

Python позволяет цепочки: `0 <= x < 10`.

`elif` проверяется только если все условия выше были ложными — сработает **первая** подходящая ветка.

?? Что выведет код при x = 15?
```python

    print("B")
else:
    print("C")
```

- A и B
- B
- C
= Срабатывает первая подходящая ветка, остальные пропускаются.

?? Чем `=` отличается от `==`?
+ `=` присваивает, `==` сравнивает
- ничем
- `==` присваивает, `=` сравнивает
- `==` только для строк
= `x = 5` кладёт 5 в x; `x == 5` спрашивает «x равен 5?».

## py-04 | Циклы: for, while, range
`for` повторяет код для каждого элемента. `range` даёт последовательность чисел:

```python
for i in range(5):        # 0 1 2 3 4
    print(i)
for i in range(1, 11, 2): # 1 3 5 7 9 — от, до (не включая), шаг
    print(i)
```

`while` крутится, пока условие истинно:

```python
n = 1
while n < 100:
    n *= 2
print(n)   # 128
```

`break` — выйти из цикла сразу, `continue` — перейти к следующему шагу.

Накопление суммы — самый частый приём:

```python
s = 0
for i in range(1, 101):
    s += i
print(s)   # 5050
```

`print(..., end=" ")` печатает без перехода на новую строку.

?? Сколько раз выполнится тело `for i in range(2, 10, 3)`?
- 2
+ 3
- 8
- 10
= Значения: 2, 5, 8 — правая граница 10 не входит.

?? Что выведет код?
```python
s = 0
for i in range(4):
    s += i
print(s)
```
- 10
+ 6
- 4
- 0
= 0 + 1 + 2 + 3 = 6.

?? Что делает `break`?
+ сразу выходит из цикла
- пропускает один шаг
- останавливает программу
- начинает цикл заново
= Пропуск шага — это continue.

## py-05 | Строки и срезы
Строка — последовательность символов, к ним можно обращаться по номеру (с нуля):

```python
s = "программа"
print(s[0])     # п
print(s[-1])    # а — с конца
print(len(s))   # 9
```

**Срезы** `s[начало:конец:шаг]` (конец не входит):

```python
s[0:3]    # "про"
s[3:]     # "грамма"
s[::-1]   # "аммаргорп" — задом наперёд
```

Полезные методы: `s.upper()`, `s.lower()`, `s.replace("а", "о")`, `s.count("м")`, `s.find("гр")` (номер или -1), `s.strip()` (убрать пробелы по краям), `"-".join(["a","b"])` → `"a-b"`.

Строки **неизменяемые**: `s[0] = "П"` — ошибка. Создавай новую: `s = "П" + s[1:]`.

Перебор символов: `for ch in s:`.

- "Pyt"
+ "yth"
- "ytho"
- "Pyth"
= Индексы 1, 2, 3 — символы y, t, h. Четвёртый не входит.

?? Как перевернуть строку s?
- s.reverse()
+ s[::-1]
- reversed(s) — сразу строка
- s[-1:0]
= Срез с шагом -1 идёт с конца в начало.

## py-06 | Списки
Список хранит много значений по порядку и **изменяется**:

```python
a = [5, 3, 8]
a.append(1)      # [5, 3, 8, 1]
a[0] = 10        # [10, 3, 8, 1]
a.pop()          # убрать последний → [10, 3, 8]
print(len(a), sum(a), max(a), min(a))
```

Срезы работают как у строк: `a[1:]`, `a[::-1]`.

Сортировка: `a.sort()` меняет список, `sorted(a)` возвращает новый. По убыванию — `reverse=True`.

Прочитать список чисел из строки:

```python
nums = list(map(int, input().split()))
```

Вывести через пробел: `print(*nums)`.

Осторожно: `b = a` не копирует, а даёт второе имя тому же списку. Копия — `b = a.copy()` или `a[:]`.


+ 4
- 1
- ошибка
= b и a — один и тот же список, append виден через оба имени.

?? Чем `a.sort()` отличается от `sorted(a)`?
+ sort меняет сам список, sorted возвращает новый
- ничем
- sorted работает только с числами
- sort возвращает новый список
= a.sort() возвращает None — частая ловушка: `a = a.sort()` всё ломает.

## py-07 | Функции
Функция — именованный кусок кода, который можно вызывать много раз:

```python
def square(x):
    return x * x

print(square(4))   # 16
```

- `def имя(параметры):` — объявление
- `return` возвращает значение и сразу выходит из функции
- без return функция возвращает `None`

Параметры по умолчанию:

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

greet("Аня")              # Привет, Аня!
greet("Аня", "Здравствуй")
```

Переменные внутри функции **локальные** — снаружи их не видно.

Функция может вернуть несколько значений: `return mn, mx` → `a, b = f(...)`.

?? Что выведет код?
```python
def f(x):
    x = x + 1
    print(x)
f(3)
print(f(3))
```
- 4 и 4
+ 4, 4, None
- 4 и None
- ошибка
= f печатает 4 при каждом вызове, а возвращает None — его и печатает второй print.

?? Что делает `return`?
+ возвращает значение и завершает функцию
- печатает значение
- повторяет функцию
- ничего, это украшение
= Печатает print, а return отдаёт результат тому, кто вызвал.

!! Напиши функцию `is_prime(n)`, которая возвращает True для простых чисел. Дано число k — выведи все простые от 2 до k через пробел.
<<<
def is_prime(n):
    # твой код
    pass

k = int(input())
<<<
in: 20
out: 2 3 5 7 11 13 17 19
in: 2
out: 2
hint: Число простое, если не делится ни на одно d от 2 до √n: `d * d <= n`.
hint: `print(*[n for n in range(2, k + 1) if is_prime(n)])`
===
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

k = int(input())
print(*[n for n in range(2, k + 1) if is_prime(n)])
===
card: Что вернёт функция без `return`? :: `None`
card: Почему проверка простоты идёт только до √n? :: Если n = a·b и a > √n, то b < √n — делитель уже нашёлся бы раньше.

## py-08 | Словари и множества
**Словарь** хранит пары «ключ → значение», поиск по ключу мгновенный:

```python
ages = {"Аня": 19, "Борис": 20}
ages["Вика"] = 18          # добавить
print(ages["Аня"])         # 19
print(ages.get("Гена", 0)) # 0 — если ключа нет
for name, age in ages.items():
    print(name, age)
```

Подсчёт — классика:

```python
cnt = {}
for w in words:
    cnt[w] = cnt.get(w, 0) + 1
```

**Множество** хранит уникальные значения без порядка:

```python
s = set([1, 2, 2, 3])   # {1, 2, 3}
s.add(5)
print(3 in s)           # True — очень быстро
a & b, a | b, a - b     # пересечение, объединение, разность
```

?? Что выведет `len(set("банан"))`?
- 5
+ 3
- 2
- 4
= Уникальные буквы: б, а, н.

?? Что будет при `d["нет_такого"]`, если ключа нет?
- вернёт None
+ ошибка KeyError
- вернёт 0
- создаст ключ
= Без ошибки — через `d.get(ключ, значение_по_умолчанию)`.

!! Дана строка из слов через пробел. Выведи самое частое слово и сколько раз оно встретилось (через пробел). Если таких несколько — то, что раньше по алфавиту.
<<<
words = input().split()
<<<
in: кот пёс кот мышь пёс кот
out: кот 3
in: б а б а
out: а 2
hint: Посчитай словарём: `cnt[w] = cnt.get(w, 0) + 1`.
hint: Найди максимум: `best = min(cnt, key=lambda w: (-cnt[w], w))`.
===
words = input().split()
cnt = {}
for w in words:
    cnt[w] = cnt.get(w, 0) + 1
best = min(cnt, key=lambda w: (-cnt[w], w))
print(best, cnt[best])
===
card: Как безопасно взять значение из словаря, если ключа может не быть? :: `d.get(key, default)`
card: Почему `x in set` быстрее, чем `x in list`? :: Множество ищет по хешу за O(1), список перебирает все элементы — O(n).

## py-09 | Генераторы списков, sorted и lambda
Генератор списка — список в одну строку:

```python
squares = [x * x for x in range(10)]
evens = [x for x in nums if x % 2 == 0]
```

`sorted` и `max`/`min` принимают `key` — по чему сравнивать:

```python
words = ["яблоко", "кот", "арбуз"]
sorted(words, key=len)            # ['кот', 'арбуз', 'яблоко']
sorted(words, key=len, reverse=True)
students = [("Аня", 5), ("Боря", 3)]
max(students, key=lambda s: s[1])   # ('Аня', 5)
```

`lambda x: выражение` — маленькая функция без имени.

Ещё полезное: `enumerate(a)` — пары (номер, элемент), `zip(a, b)` — идти по двум спискам сразу, `any`/`all` — есть ли хоть один / все ли True.

?? Что даст `[x * 2 for x in range(4) if x % 2]`?
- [0, 2, 4, 6]
+ [2, 6]
- [1, 3]
- [0, 4]
= Остаются нечётные x = 1 и 3, умноженные на 2.

?? Что делает `key=len` в `sorted(words, key=len)`?
+ сортирует по длине слова
- оставляет только длинные слова
- сортирует по алфавиту
- считает слова
= key — функция, по результату которой сравниваются элементы.

!! В первой строке n — число студентов. Дальше n строк «Имя балл». Выведи имена по убыванию балла; при равенстве — по алфавиту. Каждое имя на своей строке.
<<<
n = int(input())
<<<
in: 4\nАня 90\nБоря 75\nВика 90\nГлеб 60
out: Аня\nВика\nБоря\nГлеб
hint: Собери список пар: `name, score = input().split()`, балл переведи в int.
hint: `sorted(people, key=lambda p: (-p[1], p[0]))`
===
n = int(input())
people = []
for _ in range(n):
    name, score = input().split()
    people.append((name, int(score)))
for name, _ in sorted(people, key=lambda p: (-p[1], p[0])):
    print(name)
===
card: Как отсортировать по убыванию числа, а при равенстве по имени? :: `key=lambda p: (-p.score, p.name)` — кортеж сравнивается по порядку.

## py-10 | Ошибки и исключения
Когда что-то идёт не так, Python бросает **исключение**: `ValueError`, `ZeroDivisionError`, `KeyError`, `IndexError`… Их можно поймать:

```python
try:
    x = int(input())
    print(10 / x)
except ValueError:
    print("это не число")
except ZeroDivisionError:
    print("на ноль делить нельзя")
finally:
    print("готово")   # выполнится всегда
```

Свою ошибку бросают через `raise`:

```python
def sqrt(x):
    if x < 0:

```

Файлы открывают через `with` — он сам закроет файл:

```python
with open("data.txt", encoding="utf-8") as f:
    for line in f:
```

## py-12 | Рекурсия
Рекурсия — когда функция вызывает саму себя на задаче поменьше. Обязательно нужен **базовый случай**, где она останавливается:

```python
def fact(n):
    if n == 0:        # базовый случай
        return 1
    return n * fact(n - 1)
```

Классика — перебор вариантов:

```python
def gen(prefix, n):
    if len(prefix) == n:
        print(prefix)
        return
    for ch in "01":
        gen(prefix + ch, n)
```

Наивная рекурсия бывает медленной: `fib(n) = fib(n-1) + fib(n-2)` считает одно и то же много раз. Лечится **запоминанием**:

```python
from functools import lru_cache

@lru_cache(None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Глубина рекурсии в Python ограничена (~1000 вызовов).

?? Что будет, если у рекурсии нет базового случая?
- вернёт 0
+ бесконечные вызовы → RecursionError
- функция выполнится один раз
- ничего
= Каждый вызов порождает новый, пока не кончится стек.

?? Сколько строк выведет `gen("", 3)` из примера выше?
- 3
- 6
+ 8
- 9
= Все строки из 0 и 1 длины 3: 2³ = 8.

        print(s)

## py-13 | Сложность и бинарный поиск
Важно не только «работает», но и «как быстро». Сложность считают в O-нотации — как растёт число действий от размера n:
- O(1) — доступ `a[i]`, `x in set`
- O(log n) — бинарный поиск
- O(n) — один проход по списку
- O(n log n) — сортировка
- O(n²) — два вложенных цикла

При n = 10⁵ O(n²) — это 10¹⁰ действий: не успеет. O(n log n) — около 2·10⁶: мгновенно.

**Бинарный поиск** в отсортированном списке: смотрим середину и выкидываем половину.

```python
def find(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

Готовое в библиотеке: `from bisect import bisect_left, bisect_right`.

?? Сколько шагов бинарного поиска нужно максимум на 1 000 000 элементов?
- 1000
- 100
+ около 20
- 1 000 000
= Каждый шаг делит пополам: 2²⁰ ≈ 10⁶.

?? Какая сложность у двух вложенных циклов по n?
- O(n)
+ O(n²)
- O(log n)
- O(2n)
= n проходов по n действий.

===

!! Дан неориентированный граф: в первой строке n (вершины 1..n) и m (рёбра), дальше m строк «u v», в последней — s. Выведи расстояния (в рёбрах) от s до всех вершин через пробел; недостижимым — -1.
<<<
from collections import deque
n, m = map(int, input().split())
<<<
in: 5 4\n1 2\n2 3\n1 4\n4 3\n1
out: 0 1 2 1 -1
hint: Список смежности: `g = [[] for _ in range(n + 1)]`.
hint: BFS: в очередь s, dist[s] = 0; берём вершину, для соседей с dist == -1 ставим dist + 1 и кладём в очередь.
===
from collections import deque
n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)
s = int(input())
dist = [-1] * (n + 1)
dist[s] = 0
q = deque([s])
while q:
    v = q.popleft()
    for to in g[v]:
        if dist[to] == -1:
            dist[to] = dist[v] + 1
            q.append(to)
print(*dist[1:])
===

card: Какая структура нужна для обхода графа в ширину (BFS)? :: Очередь — `collections.deque`.
